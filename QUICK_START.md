## 🔧 TROUBLESHOOTING (2 minutes)

### Problem: "Input file not found"
**Solution**: 
- Check the file path is correct
- Make sure HDFS is running (if using HDFS path)
- Or browse for local CSV file

### Problem: "Permission denied"
**Solution**:
- Check output folder exists
- Verify write permissions
- Try different folder

### Problem: "Analysis is already running"
**Solution**:
- Wait for it to complete
- Or click "⏹️ Stop" button

### Problem: Spark not available
**Solution**:
- Make sure Docker containers are running
- Or install: `pip install pyspark`
