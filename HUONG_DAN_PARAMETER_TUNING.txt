========================================================================
BƯỚC 2B: DÙNG CUSTOM (NÂNG CAO)
========================================================================

1. SCROLL XUỐNG tìm dòng:
   ☐ Use custom parameters

2. CLICK vào checkbox để bật:
   ☑ Use custom parameters

3. Ô nhập tham số sẽ HIỆN RA:
   
   ┌─────────────────────────────────┐
   │ Rank (latent factors):          │
   │ [ 50                         ]  │
   │ Higher = better but slower      │
   │                                 │
   │ Alpha (confidence):             │
   │ [ 40.0                       ]  │
   │ Implicit feedback weight        │
   │                                 │
   │ RegParam (regularization):      │
   │ [ 0.1                        ]  │
   │ Lower = less regularization     │
   │                                 │
   │ MaxIter (iterations):           │
   │ [ 20                         ]  │
   │ More = longer training          │
   └─────────────────────────────────┘

4. THAY ĐỔI giá trị trong các ô

KHUYẾN NGHỊ CUSTOM:
- Rank: 60-100
- Alpha: 40-60
- RegParam: 0.03-0.1
- MaxIter: 20-35

NẾU MUỐN STOP
========================================================================

1. Click nút "⏹️ Stop" (màu đỏ, dưới Start Training)

========================================================================
NẾU BỊ LỖI "Workers not ready"
========================================================================

Chạy lệnh sau trong terminal:

docker restart gui-docker-spark-worker-1 gui-docker-spark-worker-2

Đợi 30 giây rồi thử lại.
