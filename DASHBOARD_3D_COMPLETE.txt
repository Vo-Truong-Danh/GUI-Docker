## 📊 DATA FILES REQUIRED

### Primary: tmp/customer_rfm_3d.json
Generated by code7.py

Format: JSON Lines
```json
{"Customer_ID":"12345","Recency":45,"Frequency":12,"Monetary":5432.50,"prediction":0}
{"Customer_ID":"67890","Recency":321,"Frequency":2,"Monetary":150.00,"prediction":1}
```

Fields:
- Customer_ID: Unique customer identifier
- Recency: Days since last purchase
- Frequency: Total number of purchases
- Monetary: Total spending (£)
- prediction: Cluster ID (0=Gold, 1=Lost, 2=Loyal)

### Secondary: tmp/ml_analysis_summary.json
For stats cards & segments table

Format: JSON Object
```json
{
  "total_revenue": 8294000.50,

  "avg_order_value": 15.30,
  "ml_models": { "linear_regression": { "r2_score": 0.857 } },
  "customer_segments": [...]
}
```

### Code7.py Enhancements
Added RFM data export:
```python
# Calculate Recency
max_date = df_clean.agg(_max(col(date_col))).collect()[0][0]
customer_rfm_full = df_clean.groupBy(customer_col).agg(
    datediff(lit(max_date), _max(col(date_col))).alias("Recency"),
    count("Invoice").alias("Frequency"),
    _sum("Revenue").alias("Monetary")
)

# Join with clusters
customer_rfm_with_cluster = customer_rfm_full.join(
    customer_clustered.select(customer_col, "cluster"),
    on=customer_col,
    how="inner"
)

# Export to JSON
customer_rfm_with_cluster.write.json("tmp/customer_rfm_3d_temp")
```

## ⚠️ TROUBLESHOOTING

### Issue: 3D chart not showing
Solution:
1. Check console (F12) for errors
2. Verify ECharts GL CDN loaded
3. Hard refresh (Ctrl+Shift+R)
4. Check customer_rfm_3d.json exists

### Issue: "RFM data not found"
Solution:
1. Run code7.py to generate data
2. Dashboard auto-uses sample data as fallback

### Issue: Port 8000 already in use
Solution:
```powershell
# Stop process using port 8000
Get-Process -Id (Get-NetTCPConnection -LocalPort 8000).OwningProcess | Stop-Process

# Or use different port
python -m http.server 8080
```
