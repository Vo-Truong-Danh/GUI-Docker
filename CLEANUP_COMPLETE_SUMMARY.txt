SCRIPT HOẠT ĐỘNG THẾ NÀO:
========================================================================
  
  CLEAN_KEEP_HDFS_INPUT.bat:
  
  1. Xóa stopped containers, unused volumes/images
  2. Stop containers (docker-compose down)
  3. YÊU CẦU: BẠN tắt Docker Desktop manual
  4. Compact VHDX: 244GB → ~40GB (10-15 phút)
  5. YÊU CẦU: BẠN mở Docker Desktop lại
  6. Start containers: docker-compose up -d
  7. Verify input data: hdfs dfs -du -s -h /input/data/
  
  KẾT QUẢ:
  - C: drive +200GB free space
  - Input data 31.2GB vẫn ở HDFS (KHÔNG MẤT!)


TẠI SAO PHẢI TẮT DOCKER MANUAL?
========================================================================
  
  - Auto stop (wsl --shutdown) KHÔNG ĐỦ
  - Docker còn processes chạy ngầm
  - DiskPart không compact được: "file in use"
  
  → Manual stop (Quit Docker Desktop) → Chắc chắn stop hoàn toàn
  → DiskPart compact thành công!
