Giới thiệu Dự án

Dashboard này trình bày kết quả phân tích Big Data từ dữ liệu bán lẻ trực tuyến thực tế với 805,549 giao dịch, sử dụng Apache Spark và Machine Learning.

Công nghệ sử dụng:

  • Apache Spark 3.3.0 - Xử lý phân tán Big Data
  • Docker - Container hóa Spark Cluster (Master + Workers)
  • Python & PySpark - ETL và phân tích dữ liệu
  • Scikit-learn - Machine Learning (K-Means, Random Forest, Linear Regression)
  • Plotly.js - Trực quan hóa 3D tương tác
  • Matplotlib & Seaborn - Biểu đồ thống kê

Các phân tích chính:

  • Phân cụm Khách hàng (K-Means) - 5 phân khúc: VIP, High-Value, Regular, Growing, New
  • Dự đoán Doanh thu (Regression) - Random Forest đạt R² = 0.726
  • Phân loại Sản phẩm (Clustering) - 4 nhóm: Bestsellers, Popular, Niche, Regular
  • Phân tích Xu hướng - Doanh thu theo thời gian, quốc gia, sản phẩm
  • Dashboard 3D Tương tác - Khám phá dữ liệu đa chiều
