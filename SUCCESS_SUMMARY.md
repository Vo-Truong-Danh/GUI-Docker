💡 TIPS & TRICKS
=================

Performance:
• Use HDFS for large datasets (> 100MB)
• Output to SSD for faster save
• Increase Spark executor memory for big data
• Select only needed analysis types

Customization:
• Modify cluster numbers (k parameter)
• Adjust visualization DPI
• Add more ML algorithms
• Customize colors and styles

Integration:
• Combine with Spark Runner tab
• Link with HDFS Upload tab
• Export results to cloud storage
• Integrate with reporting tools

Troubleshooting:
• Check console output first
• Verify file paths are correct
• Ensure write permissions
• Check Docker containers running


🔧 CONFIGURATION
=================

Basic Setup:
```python
config = {
    'hdfs_host': 'hdfs://namenode:8020',
    'hdfs_default_path': '/user/spark/data'
}
```

Advanced Setup:
```python
config = {
    'hdfs_host': 'hdfs://namenode:8020',
    'spark_master': 'spark://spark-master:7077',
    'spark_executor_memory': '8G',
    'spark_executor_cores': '8',

}
```
