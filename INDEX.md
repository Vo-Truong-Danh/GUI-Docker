## 🆘 Getting Help

### Common Issues

**Q: Tool not found**  
A: Ensure you're in correct directory: `cd run_spark_gui`

**Q: Import errors**  
A: Check Python version (3.7+) and install requirements

**Q: Permission denied**  
A: Run with appropriate permissions or check file ownership

**Q: Dashboard won't open**  
A: Install tkinter: `pip install tk` or use system package manager

### Support Channels
1. Check documentation (this index)
2. Review error logs in `logs/`
3. Read generated reports
4. Check TODO comments in code
