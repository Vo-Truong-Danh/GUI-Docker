## 📞 Finding Help

### Problem: Dashboard not opening
**Read**: HTML_DASHBOARD_INTEGRATION_GUIDE.md → Troubleshooting → "Dashboard shows no data"
**Do**: Check /tmp/ml_analysis_summary.json exists

### Problem: Charts not loading
**Read**: HTML_DASHBOARD_INTEGRATION_GUIDE.md → Troubleshooting → "Charts not loading"
**Do**: Clear browser cache, reload page

### Problem: Data not updating
**Read**: HTML_DASHBOARD_INTEGRATION_GUIDE.md → Troubleshooting → "Data not updating"
**Do**: Run new analysis, verify /tmp/ files exist

### Problem: Button not visible in Tkinter
**Read**: FINAL_SUMMARY_COMPLETE.md → Integration Points
**Do**: Check ml_analytics_tab.py has the button code

### Problem: Customization not working
**Read**: HTML_DASHBOARD_COMPLETE_GUIDE.md → Customization Options
**Do**: Check syntax, clear browser cache, reload

### Problem: Deployment issues
**Read**: FINAL_SUMMARY_COMPLETE.md → Deployment Checklist
**Do**: Run verify_dashboard_setup.py, check file permissions
